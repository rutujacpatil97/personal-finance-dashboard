## ✨ Features

### 📊 Dashboard
- **Summary cards** for total income, total expenses and savings rate
- **Income vs expenses trend**: a line chart of the last 6 months
- **Spending by category**: a donut chart with amounts and percentages
- **Monthly budgets**: set a limit per category and watch the progress bar go from green to amber to red
- **Smart tips**: personalised advice based on your own spending (see [how the tips work](#-how-the-smart-tips-work))

### 💳 Transactions
- Add income or expenses with a **description, amount, category and date**
- The category list changes with the type (expense or income)
- **Search** by description or category (debounced, so it stays smooth)
- **Export to CSV** (exports what you currently see in the list)
- Delete a transaction with one click
- Amounts are colour coded: green for income, red for expenses

## 🛠️ Tech Stack

| | |
|---|---|
| **Framework** | Angular 18 (NgModules, lazy loaded routes) |
| **State** | Angular **Signals** (`signal`, `computed`, `effect`) |
| **Forms** | Reactive Forms with validation |
| **Async** | RxJS (debounced search) |
| **Styling** | SCSS with CSS variables |
| **Charts** | Hand written SVG (donut and line chart) |
| **Mock API** | [json-server](https://github.com/typicode/json-server) |

### Why Signals?
Signals give synchronous, fine grained reactivity without manual subscriptions. Derived values such as the total balance, the category chart and the tips are `computed` signals, so they update by themselves when a transaction is added or deleted.

## 🚀 Getting Started

### Prerequisites
- Node.js 18 or newer
- Angular CLI (`npm install -g @angular/cli`)

### Run it locally

You need **two terminals**: one for the mock API and one for the app.

```bash
# 1. Install dependencies
npm install

# 2. Terminal 1: start the mock API on port 3000
npx json-server --watch db.json --port 3000

# 3. Terminal 2: start the app
ng serve
```

Open **http://localhost:4200** 🎉

You can also check the API directly:
- http://localhost:3000/transactions
- http://localhost:3000/budgets

> **Note about the sample data:** the trend chart always shows the *last 6 months from today*. The sample transactions in `db.json` are dated May to October 2026, so if you run the project much later, edit the dates in `db.json` to see the charts filled in.

## 🧠 How the Smart Tips Work

The tips are generated by simple, readable rules in `src/app/utils/spending.ts`. There is no AI involved. Each rule is a threshold plus a sentence template, and the numbers in the sentence come from your own data.

| Rule | Example tip |
|---|---|
| Savings rate below 0, below 20%, or above 20% | "You are saving 69% of your income..." |
| A category over its monthly budget | "You are over your Food & Dining budget by ₹1,150." |
| A category close to its limit (80%+) | "You have used 92% of your Bills & Utilities budget." |
| Spending vs last month (15% or more change) | "Your spending is 18% higher than last month." |
| One category taking 30%+ of spending | "Shopping takes 34% of your spending." |
| High food or entertainment share | "Entertainment is 12% of your expenses..." |

Because the tips are `computed` signals, they refresh instantly when your data changes.

### How does the SVG donut show dynamic values?
A circle with radius `15.9155` has a circumference of almost exactly **100**, so a percentage can be used directly as a stroke length. For each category the app calculates a `stroke-dasharray` (how much to draw) and a `stroke-dashoffset` (where the slice starts), and Angular binds them to one `<circle>` per category.

## 🔌 API (json-server)

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/transactions` | List all transactions |
| POST | `/transactions` | Add a transaction |
| DELETE | `/transactions/:id` | Delete a transaction |
| GET | `/budgets` | List budgets |
| POST / PATCH / DELETE | `/budgets` | Create, update or remove a category budget |

A transaction looks like this:

```json
{
  "id": "6",
  "title": "Groceries",
  "amount": -3500,
  "category": "Food & Dining",
  "date": "2026-10-10"
}
```

Positive amounts are income and negative amounts are expenses.
